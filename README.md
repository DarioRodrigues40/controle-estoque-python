# 📦 Sistema de Controle de Estoque

Projeto desenvolvido em Python para gerenciamento de produtos em estoque através de um menu interativo no terminal.

---

## 🎯 Objetivo

Permitir o cadastro e consulta de produtos, aplicando validações para garantir a integridade dos dados informados pelo usuário.

---

## 🚀 Funcionalidades

✅ Cadastro de produtos

✅ Validação de código único

✅ Validação de código com 5 dígitos

✅ Validação de nome contendo apenas letras

✅ Validação de preço e quantidade não negativos

✅ Consulta dos produtos cadastrados

✅ Armazenamento em lista de dicionários

✅ Utilização de funções e recursividade

---

## 🧱 Estrutura dos Dados

Cada produto é armazenado da seguinte forma:

```python
{
    "codigo": "12345",
    "nome": "Mouse",
    "preco": 50.00,
    "quantidade": 10
}
```

---

```text
===== CONTROLE DE ESTOQUE =====
```
